# Description

Youtube Channel: [Remove Before Flight](https://www.youtube.com/@RemoveBeforeFlightED)



AeroGNC-Lab is my work developing a flight control development enviroment. I want to share my work and the process of developing this by creating a youtube course to show flight dynamics, GNC, and software design principles for autonomous aircraft. 

The vision for this project is to develop 3-Dof and 6-Dof simulations for aircraft controller design and development along with the tools for aircraft analysis. Building up the simulation brick by brick from longitudinal only motion to the full 6-Dof simulation and a 3-Dof planer ground model the entire aircraft mission can be modeled such that a mission can be planned and the aircraft executes. Starting from first principles and then moving into aircraft being modeled from their geometry or from flight data, this project aims to provide the oupportunity to demonstrate what a professional controls engineer goes through to develop flight software.

This project is for educational pourposes only and is no way a certified simulation enviroment and should not be used for crewed aircraft controller development.

**From equations to autonomous flight. Build the model. Design the controller. Fly the mission.**
